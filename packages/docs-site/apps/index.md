# Apps

Explore eight complete JSVision applications, running directly in your browser. Each one focuses on
a different part of the framework: application chrome, reactive controls, editing, window
management, custom views, animation, themes, or truecolor rendering.

New to JSVision? Start with **[Hello, JSVision](./hello)**. Want the full experience? Jump straight
to the **[Turbo Vision desktop](./desktop?example=apps%2Fdesktop)**.

## Featured: Turbo Vision desktop

The flagship application puts the pieces together: menu and status bars, keyboard focus, movable
and resizable windows, and tile and cascade commands. It is the same `@jsvision/ui` application you
would run in a terminal, hosted here in the browser.

## Build your own

When you are ready to move from exploring to building, start with the
**[Application Shell](/guide/application-shell)** course and continue to the
**[Complete Application](/guide/complete-application)** course. Use the
**[component catalog](/components/)** to choose controls, or read
**[Running in the Browser](/guide/running-in-the-browser)** to understand how the same application
runs inside these live examples.

The complete source for every showcase is available in the
**[JSVision repository](https://github.com/blendsdk/jsvision/tree/develop/packages/docs-site/examples/apps)**.
